# ai-profile — design context for tooling

Canonical design documents (read these; this file only points at them):

- `DESIGN.md` — the visual contract: tokens, type scale, composition grammar,
  signal rules, review checklist.
- `docs/decisions/ADR-032-collaboration-pulse.md` — the v0.8.1 Collaboration
  Pulse decision (summary card daily block only).
- `docs/decisions/ADR-031-signal-console.md` — the v0.8.0 Signal Console
  decision (dashboard, summary SVG, heatmap SVG, badge).
- `docs/decisions/ADR-025-flat-evidence-ledger.md`,
  `ADR-029-provider-ledger-only-rendering.md`, `ADR-021`, `ADR-020` — the
  underlying semantics that no restyle may change.
- `docs/PRIVACY.md` — the privacy boundary every rendered byte must respect.

## Audience

General GitHub visitors (recruiters, collaborators, curious engineers) who
land on a Profile README card or the linked dashboard for roughly five
seconds, on phones as often as desktops. Maintainers and design-aware agents
are the secondary audience.

## Task

Answer, fast and honestly: how much explicitly attributed AI collaboration is
recorded, how sustained it is, which providers took part, and what evidence
and publication scope back the numbers. Nothing is a skill score.

## Tone

Calm, precise, instrument-like. Tech feeling from information architecture,
status treatment, alignment, typography, and data interaction — never from
decoration.

## Constraints

- Renderers consume validated `VizStats` only; one self-contained HTML
  document, restrictive CSP, zero network requests, deterministic bytes,
  exactly eight public output filenames.
- Local/system font stacks only; no remote assets, frameworks, or trackers.
- Unknown is not human; provider counts may overlap; the daily pulse/map
  shows publishable dates only; `generated_on` is a *snapshot*, never "live".
- Summary and heatmap SVGs stay 830 wide; the badge stays 24 high.
- Banned: neon, glassmorphism, gradients, gradient text, oversized hero,
  thin border + large shadow, thick side accent stripes, uppercase tracked
  labels, monospace-as-tech, width/layout-property transitions. Motion is
  transform/opacity only and off under `prefers-reduced-motion`.
- Snapshots regenerate only via `python tests/unit/test_render_summary.py`
  and `python tests/unit/test_heatmap_svg.py`.
