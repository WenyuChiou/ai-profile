## Findings

### Medium — publication and live Profile gates (closed)

**Description:** The authoritative Ubuntu build and exact-wheel onboarding on
Ubuntu, Windows, and macOS passed in CI run `30934549387`. The tag/PyPI
publication and maintainer Profile refresh were initially open in the candidate
review. The exact tag, PyPI files, GitHub Release, and Profile Pages outputs
have now been verified.

**Impact:** Before closure, users could not install the model-family release
from PyPI and the public example still pointed at the previous release. No
remaining user-facing impact was observed after the release and Profile
checks.

**Recommendation:** Keep the frozen Ubuntu digest pinned and repeat the same
artifact, clean-install, and live-Profile checks for future releases. **Disposition:
closed** by publish run `30935872159`, Profile PR #15, Pages run `30937320357`,
and the exact live-byte comparison above.

### Low — additive legacy `VizStats` compatibility

**Description:** A manually constructed legacy `VizStats` may keep `models=()`
with nonzero AI totals. The production privacy builder supplies model rows for
every AI/mixed presence and the renderer states when explicit model evidence is
not published.

**Impact:** External callers bypassing the production builder can omit model
evidence without a validation error.

**Recommendation:** Keep the additive compatibility in v0.5.0; document it as
an internal fixture compatibility rule and consider requiring model rows in a
future contract/schema bump.
