## Findings

### Medium — release authority and cross-platform gates are still open

**Description:** The current digest was built on Windows. The repository's CI
and publish workflows intentionally rebuild the authoritative wheel on Ubuntu
and then run exact-wheel onboarding on Ubuntu, Windows, and macOS.

**Impact:** A local green run cannot prove the exact bytes, packaging metadata,
or platform onboarding that will be promoted to users.

**Recommendation:** Push the reviewed branch, require green CI and the staging
workflow, freeze the Ubuntu wheel/sdist digests, then publish those exact bytes
and rerun clean installs from PyPI before updating the maintainer Profile.

### Low — additive legacy `VizStats` compatibility

**Description:** A manually constructed legacy `VizStats` may keep `models=()`
with nonzero AI totals. The production privacy builder supplies model rows for
every AI/mixed presence and the renderer states when explicit model evidence is
not published.

**Impact:** External callers bypassing the production builder can omit model
evidence without a validation error.

**Recommendation:** Keep the additive compatibility in v0.5.0; document it as
an internal fixture compatibility rule and consider requiring model rows in a
future contract/schema bump.

## Final recommendation

**NO-GO — pending Ubuntu CI, cross-platform onboarding, publication, and live Profile verification.**
