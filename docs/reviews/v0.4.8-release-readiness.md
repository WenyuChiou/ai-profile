# v0.4.8 release readiness

Date: 2026-08-01

## Executive conclusion

v0.4.8 (the HR-first visual refresh, ADR-022) is released as a **Public
Beta** — not Stable/GA. Every release gate passed with byte-exact
artifacts: the canonical wheel, the package dashboard, and the maintainer
Profile outputs published exactly the pinned bytes; the full test, privacy,
dogfood, and browser evidence below is green; the three accepted
nonblockers are documentation- or presentation-level and are recorded with
their dispositions.

## Scope

The HR-first visual refresh: summary card redesigned as the recruiter-first
`AI Collaboration Record` with the whole-rhythm isometric terrain (height =
total-commit bins, hue = AI-share bins, provider-independent geometry),
dashboard headline alignment, README restructure, and refreshed
banner/social assets. Product semantics — ACE, aggregation, privacy modes,
CLI — are unchanged. Import, reconciliation, richer views, GitHub API
integration, and any configuration CLI remain outside the v0.4.8 boundary.
