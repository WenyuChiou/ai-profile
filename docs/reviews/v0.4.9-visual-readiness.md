## Findings

### Medium — Release artifact and public links still identify v0.4.8

**Description:** The refined SVG bytes are verified on this design branch, but
the public tag, PyPI wheel, GitHub Release, Pages dashboard, and profile README
still represent the already released v0.4.8 artifact. The branch intentionally
does not claim a new version or upload.

**Impact:** Publishing the new visual without a versioned candidate and the
existing candidate-lock / cross-platform / Pages checks would make the public
artifact provenance ambiguous.

**Recommendation:** Merge this branch through the normal PR checks, create a
new patch version only after the release owner updates the candidate metadata,
run the Linux/Windows/macOS clean-wheel workflow and final public URL checks,
then regenerate the profile README from that exact verified wheel. Until those
steps occur, treat this branch as a release candidate rather than a public
release.
