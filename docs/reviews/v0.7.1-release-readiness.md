## Executive summary

`ai-profile` v0.7.1 is published and verified for Public Beta use. The v0.7
line adds local batch refresh, persistent native scheduling, exact-eight Git
publication, and a public-only reusable GitHub Actions path. The v0.7.1 patch
normalizes the Windows Task Scheduler ownership shape observed after real
registration. ACE schema `0.3.0`, aggregation, `VizStats`, privacy semantics,
renderers, and the eight output names remain unchanged.

The release, staging, disposable public caller, maintainer Profile scheduler,
Profile Pages, and final visual checks are closed. The GitHub Release remains
marked prerelease and the PyPI classifier remains Beta.
