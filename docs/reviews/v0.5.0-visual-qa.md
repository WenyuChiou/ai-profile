## Static and accessibility contracts

- Model marks are neutral two-character category marks (`Cl`, `Gp`, `Ge`,
  etc.), not provider logos and not raw model names.
- Unknown is shown as its own `Unknown` row when present; it is never rendered
  as Human.
- Model percentages are explicitly labelled non-exclusive and use the
  AI-attributed-commit denominator.
- Summary `<desc>` text distinguishes known-only rows, an unknown bucket, and
  overflow rows hidden below the top-four ledger.
- SVG snapshots/assets are deterministic, XML-well-formed, and contain no
  scripts, event-handler attributes, external references, or private canaries.
- Dashboard CSP and no-network checks passed; no external font request exists.
