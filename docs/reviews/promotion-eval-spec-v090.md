# v0.9.0 Public Beta evaluation contract

Frozen before candidate dogfood on 2026-09-06. Source baseline:
`c2a014aa9ad946fe867c2f513d76353759d55741`. The user-approved amended
Collaboration Mine plan and ADR-033 define the visual scope. This contract
does not weaken the release runbook's artifact, privacy or onboarding gates.

- Candidate identity is the exact Linux-built wheel and staging-dashboard
  SHA-256 in `promotion-candidate.json`, with its frozen SOURCE_DATE_EPOCH.
- All four README-only roles remain required: newcomer, privacy-sensitive,
  overlapping providers, and Profile publisher. Each receives only the two
  READMEs, wheel and role objective; no source/tests or product hints. Each uses
  an isolated home, repository and environment under the declared scratch root.
- Pass requires 4/4 roles, exact hand-derived counts, zero private-canary hits,
  no configuration dead ends, exact eight outputs and repeated byte equality.
  A candidate byte change invalidates affected evidence; failures stay recorded.
- Full pytest, Ruff, bilingual parity/preset, sanctioned snapshot regeneration,
  installed-wheel smoke, independent staged-diff/security review and all eight
  required GitHub jobs must pass before merge. Merge retains the reviewed C1
  immutable workflow commit; publication verifies exact artifact digests.
- Visual evidence covers all selected dates, linear AI/Other columns, stable
  provider highlights, nonoverlapping dates, original continuous SVG actors,
  readable workstations/evidence, 195–1440px, light/dark, true 1x/2x SVG raster,
  keyboard/touch, pause, reduced motion and static print. Accepted visual
  receipts remain valid only while the relevant renderer bytes are unchanged.
- After publication, run the authorized public-only Profile caller twice:
  changed exact-eight commit plus Pages, then unchanged with no commit; verify
  live assets/HTTP 200 and the enabled default-branch daily schedule. This real
  Profile is the authorized hosted E2E target; do not create another public repo
  or a local schedule for this task.
- Release remains Public Beta, not Stable. No ACE/VizStats/CLI/privacy/output
  name changes. Unresolved correctness, privacy, artifact or CI failures block
  promotion. Reports distinguish local evidence from actual cloud execution.
