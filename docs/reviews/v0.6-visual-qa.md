## Visual judgement

The resulting surface is a flat evidence ledger: opaque background, hairline
borders, restrained blue signal, warm evidence rail, local font fallbacks, and
no gradients, glass, animation, perspective, or decorative background pattern.
The model panel is visually distinct but subordinate to the headline and daily
activity overview. This is intentionally closer to a professional report or
instrument panel than to a generic green contribution clone.

## Privacy and static-safety spot checks

- Model output contains only canonical family labels/marks; raw model
  declarations remain outside `VizStats`.
- Daily geometry is unchanged by model rows; model values stay in the separate
  all-time ledger.
- The dashboard remains self-contained with the existing CSP and no external
  font/network dependency.
- Snapshot/sample output is generated only through the sanctioned summary
  writer.
- The stable model mark palette measured a minimum contrast of **5.95:1** on
  the light canvas and **8.77:1** on the dark canvas (above the 3:1 graphical
  mark threshold).
