# Security policy

## Supported versions

Security fixes are provided for the latest release published on
[PyPI](https://pypi.org/project/ai-profile-cli/).

## Report a vulnerability

Please use GitHub's
[private vulnerability reporting](https://github.com/WenyuChiou/ai-profile/security/advisories/new).
Do not include sensitive details in a public issue.

Include:

- the affected version and operating system;
- a minimal reproduction or proof of concept;
- the expected security or privacy impact;
- any suggested mitigation, if known.

The maintainer will validate the report, coordinate a fix and disclosure,
and credit the reporter unless anonymity is requested.
